# Contributing

Thanks for helping. Bug reports, fixes and small focused features are all welcome.

1. Open an issue first for anything larger than a bug fix, so we can agree on the approach.
2. Keep the project dependency-free at runtime. The UI uses vendored Preact + htm with no build step.
3. Run `npm test` before opening a pull request, and add a test when you change attendance calculations.
4. Use synthetic data in issues, screenshots and fixtures. Never include real employee names, photos or locations.

By contributing you agree that your work is released under the MIT license.
